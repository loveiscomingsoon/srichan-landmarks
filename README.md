# ศรีจันทร์ ขอนแก่น — ร่วมเติมแลนด์มาร์ก 3 เขต

[เปิดแผนที่ศรีจันทร์ 3D และวางกิจกรรม](https://loveiscomingsoon.github.io/srichan-landmarks/3d/) · [วิธีใช้และที่มาข้อมูล](3d/README.md)

แผนที่ 3D มีอาคาร 146 รูปทรง หมุดเดิม 17 จุด และขอบเขตสามเขต ความสูงส่วนใหญ่เป็นค่าประมาณ แผนกิจกรรมบันทึกในเบราว์เซอร์และส่งออก/นำเข้า GeoJSON ได้

## ภาพสถานที่ 17 จุด — สีส้มและน้ำเงินคราม

[ดูภาพและดาวน์โหลดแยกรายสถานที่](https://loveiscomingsoon.github.io/srichan-landmarks/images/landmarks/) · [ไฟล์ภาพ](images/landmarks/) · [ข้อมูลหมุดพร้อมรูป](srichan-creative-map-17-with-artwork.geojson)

ภาพดัดแปลงด้วย AI จากภาพหมายเลข 1–17 ในแผนที่ศรีจันทร์ CREATIVE MAP ที่ผู้ใช้ให้ ใช้สื่อสารย่าน ไม่ใช่ภาพถ่ายบันทึกสภาพปัจจุบัน รายละเอียดอาคารและป้ายอาจคลาดเคลื่อน ชื่อไฟล์ 01.jpg–17.jpg ตรงกับหมายเลขภาพต้นฉบับและหมุดในชั้น Creative Map ข้อมูลตำแหน่งและสถานะรอตรวจภาคสนามยังคงเดิม

[เปิดแผนที่และร่วมเพิ่มจุด](https://umap.openstreetmap.fr/en/map/3_1471827)

[![สแกนเพื่อเปิดแผนที่และร่วมเติมแลนด์มาร์ก](srichan-qr.png)](https://umap.openstreetmap.fr/en/map/3_1471827)

## วิธีเพิ่มจุด

1. สแกน QR code หรือกดลิงก์แผนที่
2. กดปุ่มแก้ไขแผนที่ (รูปดินสอ) หากยังไม่อยู่ในโหมดแก้ไข
3. เลือก Draw a marker แล้วคลิกตำแหน่งภายในเขต 1–3
4. ใส่ชื่อแลนด์มาร์ก รายละเอียด และแนวคิดกิจกรรม ระบุว่าเป็นจุดเดิมหรือข้อเสนอใหม่
5. กด Save เพื่อบันทึกลงแผนที่ออนไลน์ร่วมกัน

แผนที่เปิดให้ทุกคนร่วมแก้ไขได้ ซึ่งรวมถึงแก้ไขหรือลบจุดเดิม โปรดตรวจสอบข้อมูลก่อนใช้จัดกิจกรรม ขอบเขตสามเขตเป็นแนวประมาณจากภาพ ไม่ใช่แนวรังวัดหรือการยืนยันสิทธิใช้งานพื้นที่

## ไฟล์และการเก็บข้อมูล

- `srichan-qr.png` / `srichan-qr.svg`: QR code เปิดลิงก์แผนที่โดยตรง
- `srichan-survey.geojson`: ขอบเขตและหมุดจากข้อมูลสำรองล่าสุด
- `umap-backup.umap`: สำรองแผนที่และการตั้งค่า ใช้กู้คืนใน uMap ได้
- `index.html`: หน้าเชื่อมแผนที่และ QR code
- `backup_umap.py`: ดาวน์โหลดข้อมูลสาธารณะโดยไม่ใช้รหัสหรือลิงก์แก้ไขส่วนตัว

GitHub Actions สำรองข้อมูลทุก 6 ชั่วโมงและเมื่อเรียก Run workflow โดยเขียน commit เฉพาะเมื่อข้อมูลเปลี่ยน หมุดที่เพิ่มจะบันทึกใน uMap ทันทีเมื่อผู้เพิ่มกด Save แล้วตามมาสำรองใน GitHub รอบถัดไป การสำรองไม่ใช่การซิงก์แบบทันที และยังขึ้นกับการเปิดใช้งาน GitHub Actions และบริการ uMap

หากตารางงานถูกพักจากการไม่มีความเคลื่อนไหวใน repository ให้เปิด workflow อีกครั้งในแท็บ Actions

### โหมดเบาสำหรับเครื่องที่ไม่รองรับ WebGL
เปิด https://loveiscomingsoon.github.io/srichan-landmarks/3d/compat.html ใช้ Canvas 2D ฉายรูปทรงอาคารเป็นสามมิติ หมุนและซูมได้ มีถนน OSM 338 ช่วง อาคาร 146 รูปทรง และสถานที่เดิม 17 จุด พร้อมเครื่องมือวางกิจกรรม ความสูงส่วนใหญ่เป็นค่าประมาณ หน้า 3D หลักสลับอัตโนมัติเมื่อเริ่มระบบกราฟิกไม่ได้ แผนกิจกรรมเก็บในเบราว์เซอร์และส่งออก GeoJSON ได้

### QR สีสัน ศรีจันทร์
QR ใหม่โทนส้ม คราฟ น้ำเงิน เปิด `/join/` ซึ่งเป็นหน้าลิงก์กลางถาวร ปรับปลายทางปุ่มดู/แก้ไขได้ใน `join/links.json` โดย QR ที่พิมพ์ไว้ยังใช้เดิมได้ ผู้ดูแล repository เป็นผู้เปลี่ยนปลายทาง ส่วนผู้ร่วมงานแก้ไขแลนด์มาร์กผ่าน uMap ตามสิทธิเดิม ไฟล์ภาพ `srichan-qr-orange-kraft.png` และ SVG ตรวจอ่านด้วย ZXing ทั้งขนาดเต็มและย่อแล้ว ข้อมูล 3D ยังไม่ซิงก์ uMap อัตโนมัติ

### ตรวจตำแหน่งก่อนเผยแพร่ 29 ตุลาคม 2026
ชื่อและพิกัด uMap/3D ตรงกัน 17/17 จุด เทียบรายการ Google Maps พิกัดตรง 10 จุด อีก 7 จุดยังระบุตำแหน่งเฉพาะไม่ได้ จึงคงพิกัดประมาณและเพิ่มหมายเหตุ ไม่ย้ายไปผลค้นหาชื่อคล้าย มีชื่อ Google แยกไว้และค้นหาในหน้า 3D ได้ รายงาน data/audits/2026-10-29-position-audit.md คง QR เดิมทุกไบต์

### มุมภาพและพื้นที่ซ้อนทับ
ปรับ 7 หมุดประมาณเป็นจุดชมมุมภาพ (2,3,4,5,11,14,16) เชื่อมบริเวณ Google Maps และภาพของแต่ละจุด ยังไม่ทราบจุดยืน/ทิศกล้องจริง ซ่อนชั้นสามโซนโดยปริยายทั้ง 3D และ uMap เก็บข้อมูลโซนไว้เปิดกลับได้ ใน uMap ชั้นเดิมมีข้อเสนอเดิม 6 จุดด้วยจึงถูกซ่อนไปพร้อมชั้นเขต ไม่ลบข้อมูล QR เดิมไม่เปลี่ยน

### แสดงหมุดเล็กใน uMap
ชั้น “จุดเล็ก — จุดเดิมและข้อเสนอ” เปิดแสดงหมุดเดิม 6 จุดแยกจากพื้นที่สามโซน ชั้นเดิมที่มีทั้งขอบเขตและหมุดสำรองยังซ่อนไว้เพื่อเก็บต้นฉบับ หน้า 3D ไม่เปลี่ยนตามคำขอ QR เดิมยังใช้ได้

### ตรวจ GIS อาคารและ 17 หมุด — 29 ตุลาคม 2026
เพิ่มหน้า `/quality/` แสดงผลตรวจตำแหน่งกับขอบอาคารรายจุด ด้วย Shapely/pyproj ใน UTM 48N มี CSV สำหรับทีมสำรวจและ KML ใช้เทียบใน Google Earth/QGIS จากเดิม OSM 146 รูปทรง เพิ่ม Overture รุ่น 2026-10-21.0 รวม 2,524 รูปทรง (OSM 147, Microsoft 284, Google Open Buildings 2,093) ยังไม่ยืนยันว่าเป็นอาคารเดียวกับสถานที่แต่ละชื่อ และพบขอบทับกัน >1 ตร.ม. 104 คู่ที่ต้องตรวจเพิ่ม

ความสูงไม่ทราบ 2,522 อาคารเก็บ `null` และแสดงแปลนบนพื้นเริ่มต้น แทนตั้ง 9 เมตรเอง อีก 2 อาคารประมาณจากจำนวนชั้น ไม่มีความสูงรังวัดเลย QR และพิกัดหมุดทั้ง 17 ไม่เปลี่ยน หมุดเล็ก uMap ยังแสดงและสามโซนยังซ่อน เครื่องมือและขั้นตอนทำซ้ำอยู่ scripts/README.md
