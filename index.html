ร่วมเติมแลนด์มาร์กศรีจันทร์ · 3 เขต

สแกน QR code หรือกดลิงก์ เพื่อเพิ่มจุดสำคัญและเสนอพื้นที่กิจกรรมใหม่ลงแผนที่ร่วมกัน

เปิดแผนที่และร่วมเติมจุด ↗
  1. กดแก้ไขแผนที่ แล้วเลือก Draw a marker
  2. คลิกตำแหน่งในเขต 1–3 ใส่ชื่อและรายละเอียด
  3. กด Save เพื่อบันทึกให้ทุกคนเห็น

แผนที่เปิดให้ทุกคนร่วมแก้ไขได้ ขอบเขตเป็นแนวประมาณสำหรับสำรวจ หมุดใหม่ใน uMap จะสำรองลง GitHub ตามรอบทุก 6 ชั่วโมง
