# ศรีจันทร์ 3D — แผนที่วางกิจกรรม

เปิดใช้งาน: https://loveiscomingsoon.github.io/srichan-landmarks/3d/

แผนที่สามมิติสำหรับสำรวจและวางแนวคิดกิจกรรมเทศกาล “สีสัน ศรีจันทร์” ใช้ MapLibre GL JS 5.6.1, แผนที่ฐาน OpenFreeMap และรูปทรงอาคาร OpenStreetMap

## วิธีใช้

1. ใช้ปุ่ม 3D / 2D หรือเข็มทิศเพื่อเปลี่ยนมุมมอง คอมพิวเตอร์ใช้คลิกขวาลากเพื่อหมุนและเอียง บนมือถือใช้สองนิ้ว
2. กดหมุดหมายเลขหรือชื่อในรายการ เพื่อดูรูป ประวัติย่อ ลิงก์ข้อมูลเดิม และ Google Maps
3. เปิด “วางกิจกรรม” เลือก “ปักจุดกิจกรรม” แล้วคลิกตำแหน่ง ใส่ชื่อ ประเภท และรายละเอียด
4. เลือก “วาดเส้นทางเดิน” คลิกจุดอย่างน้อยสองจุด แล้วกด “จบเส้นทาง” เส้นนี้เป็นแนวคิด ไม่ใช่เส้นทางนำทางที่ยืนยันแล้ว
5. แผนร่างบันทึกในเบราว์เซอร์เครื่องนี้ ส่งออก GeoJSON เพื่อเก็บสำรองหรือส่งต่อ แล้วนำเข้าในอีกเครื่องได้ การนำเข้ารวมรายการและไม่เพิ่มซ้ำหากมี ID เดิม
6. จุดกิจกรรมยังไม่ได้ซิงก์ร่วมกันอัตโนมัติ ใช้ uMap เดิมสำหรับการร่วมเพิ่มข้อมูล: https://umap.openstreetmap.fr/en/map/3_1471827

## ข้อมูลและข้อจำกัด

- ข้อมูลสถานที่เป็นชุดที่รับจาก uMap เมื่อ 29 ตุลาคม 2569 การแก้ uMap ภายหลังยังไม่เปลี่ยนหน้า 3D โดยทันที ต้องอัปเดตไฟล์ข้อมูลชุดนี้
- คงพิกัด รูป และรายละเอียดของ 17 สถานที่ รวมถึงขอบเขตสามเขตเดิม ซึ่งเป็นขอบเขตประมาณ
- หมุดสีน้ำตาลเป็นตำแหน่งประมาณตามสถานะเดิม ไม่ใช่พิกัดนำทางที่ยืนยันแล้ว
- อาคาร 146 รูปทรงจาก OpenStreetMap API เฉพาะบริเวณ 102.828,16.426 ถึง 102.842,16.435 เมื่อ 29 ตุลาคม 2569 ข้อมูลยังไม่ครอบคลุมอาคารทุกหลัง
- ไม่มีอาคารในชุดนี้ที่มีแท็กความสูง มี 2 อาคารระบุจำนวนชั้น จึงใช้จำนวนชั้น × 3 เมตร อีก 144 อาคารใช้ความสูงสมมติ 9 เมตร ปรับค่านี้ได้ด้วยแถบเลื่อน
- ความสูงและโมเดลเป็นเครื่องมือวางแนวคิด ไม่ใช่ข้อมูลรังวัด ไม่ยืนยันสภาพปัจจุบัน ขนาดอาคาร สิทธิใช้พื้นที่ หรือความปลอดภัยของเส้นทาง
- ภาพประกอบสถานที่เป็นภาพดัดแปลงด้วย AI ตามชุดภาพในโครงการ
- Google Maps ใช้เปิดเทียบภาพดาวเทียม ค้นหาสถานที่ และเส้นทางภายนอก ไม่ได้นำภาพหรือโมเดล Google มาทำสำเนาในเว็บนี้
- ต้องใช้อินเทอร์เน็ตสำหรับแผนที่ฐาน รูป และลิงก์ภายนอก ต้องใช้เบราว์เซอร์ที่รองรับ WebGL
